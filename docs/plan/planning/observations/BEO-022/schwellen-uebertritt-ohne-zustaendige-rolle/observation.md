# Schwellen-Übertritt ohne zuständige Rolle

**Sub-Area:** `*` (gesamtes Repo)

Der Lese-Schritt einer Closure erkennt den 3×-Übertritt, aber der Ausgang verlangt eine Handlung,
die der Rolle dieser Closure nicht zusteht — die Zeile bleibt ohne Ausgang stehen und wird von der
nächsten Closure geerbt.
