# Vorgeschriebener Ortswechsel macht Adresse tot

**Sub-Area:** `*` (gesamtes Repo)

Ein vom Prozess vorgeschriebener Ortswechsel macht eine Adresse in einem nach `AGENTS.md` §3.4
eingefrorenen Artefakt tot: der `git mv`, den die Baseline für die Auflösung bzw. die Closure
verlangt, ist zugleich das Ereignis, das den Zeiger auf das bewegte Artefakt bricht — und die
Quelle darf niemand reparieren.
