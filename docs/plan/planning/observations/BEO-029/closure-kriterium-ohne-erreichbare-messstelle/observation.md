# Closure-Kriterium ohne erreichbare Messstelle

**Sub-Area:** `*` (gesamtes Repo)

Ein Closure-Kriterium hält zwei Fassungen auf einer Fläche gegeneinander, auf der sie nicht
auseinanderlaufen können, und setzt dazu ein Instrument voraus, das im Prüf-Fall nicht bis zur
Messstelle läuft — die Fehlerrichtung ist *das Kriterium prüft* statt *es kann nichts finden*.
