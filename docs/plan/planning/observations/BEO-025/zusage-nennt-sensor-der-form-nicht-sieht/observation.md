# Zusage nennt Sensor, der Form nicht sieht

**Sub-Area:** `*` (gesamtes Repo)

Eine Zusage im Skript- oder Funktionskopf nennt einen Geltungsbereich, den der Code darunter nicht
hält — in der schärfsten Form nennt sie einen Sensor, der den ausgegrenzten Rest auffangen soll,
und der Sensor sieht genau diese Form nicht.
