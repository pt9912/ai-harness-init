# Konstante doppelt, eine Richtung bleibt still

**Sub-Area:** `*` (gesamtes Repo)

Dieselbe Zahl steht an zwei Orten, etwa die Matrix-Breite eines Workflows und eine Variable, die das Urteil liest. Wächst die eine Seite, fällt der Überschuss still aus dem Urteil; nur die andere Richtung färbt rot.
