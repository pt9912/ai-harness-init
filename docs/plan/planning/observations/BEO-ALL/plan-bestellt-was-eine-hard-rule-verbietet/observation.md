# Plan bestellt, was eine Hard Rule verbietet

**Sub-Area:** `*` (gesamtes Repo)

Ein Liefer-Punkt eines Slice-Plans verlangt einen Inhalt, den eine Hard Rule aus
[`AGENTS.md`](../../../../../../AGENTS.md) §3 als Falsch-Form führt; der ausführende Lauf liefert ihn
plangetreu, und erst der Review stellt den Konflikt fest. Ursache war ein Planungs-Auftrag, der den
Inhalt vorgab, ohne dass der Plan ihn gegen die Hard Rules gelesen hat.
