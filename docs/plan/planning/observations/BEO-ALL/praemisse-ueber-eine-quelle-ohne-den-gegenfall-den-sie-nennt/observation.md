# Prämisse über eine Quelle ohne den Gegenfall, den sie nennt

**Sub-Area:** `*` (gesamtes Repo)

Eine Entscheidung begründet sich mit einer Abwesenheits-Aussage über eine Quelle — *die Quelle
benennt X für keine der Klassen* —, und die Quelle trägt für eine dieser Klassen einen Satz, den
ein Vorgänger desselben Repos bereits als Präzedenzfall führt. Die Fehlerrichtung ist *die Quelle
schweigt*; die Wahl kann halten, ihre Begründung ist für die Klasse ungeprüft.
