**Stand:** verkörpert

Zielort: [`AGENTS.md`](../../../../../../AGENTS.md) §3.6 — *„benennen, was wirklich deckt"*. Eine
Zusage, die die **Regel** ankündigt, während der verdrahtete Sensor nur **eine** ihrer zwei Kanten
urteilt, nennt nicht, was deckt: sie sagt mehr zu, als der Sensor hält. Der Zielort verlangt die
Kante, nicht die Regel. Ein zweiter Herkunfts-Anker steht nicht: der Zielort ist eine
Hard-Rule-Sektion und trägt seine eigene Adresse.

**Grenze der Verkörperung, benannt.** Kein Modul aus `modules:` der
[`.d-check.yml`](../../../../../../.d-check.yml) urteilt darüber, welchen Ausschnitt einer Regel ein
anderer Sensor abdeckt; `make comment-claims` prüft, ob ein genannter Sensor **existiert**, nicht,
welche Kante er trifft — und `make mutate` fährt je Fall eine Mutation, keine Abdeckungs-Frage. Der
Sensor selbst ist dabei in Ordnung: er sitzt an einem anderen Punkt als der Satz, der ihn ankündigt.
Träger bleibt der Lauf, der die Zusage formuliert, und die Rolle, die sie abnimmt.
