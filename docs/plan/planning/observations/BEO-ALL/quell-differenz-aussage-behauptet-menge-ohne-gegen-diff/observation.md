# Quell-Differenz-Aussage behauptet eine abschließende Datei-Menge ohne Gegen-`diff`

**Sub-Area:** `*` (gesamtes Repo)

Ein Adaptions-Eintrag benennt die zwischen zwei Werkzeug-Ständen bewegten Regeldateien als
abschließende Aufzählung („bewegt sich nur …"), ohne die Menge gegen einen vollständigen
`git diff --numstat` zu prüfen. Ein einzelnes Gegenkommando widerlegt die Aufzählung (eine
übersehene Datei eines aktiven Moduls).
