# Festlegung und ihr Rumpf nennen verschiedene Reichweiten

**Sub-Area:** `*` (gesamtes Repo)

Die Überschrift einer Festlegung trägt eine andere Reichweite als ihr Rumpf. Einmal **breiter** —
die Überschrift setzt die Regel für eine Artefakt-Gattung, der Rumpf arbeitet sie für ein einziges
Artefakt aus, und der Gattungsbegriff ist nirgends abgegrenzt. Einmal **unbestimmt** — die
Überschrift nennt zwei Limitatoren nebeneinander, ohne zu sagen, ob sie kumulativ (Schnittmenge)
oder alternativ (Vereinigung) gelten; aufgelöst wird das erst von einem Satz weiter unten.

Zitiert wird die Überschrift, nicht der Rumpf: Sie ist die Adresse, unter der eine Festlegung in
anderen Artefakten erscheint. Wer sie zitiert, nimmt die weitere Lesart mit. In einem Artefakt,
das mit der Annahme einfriert, ist die Differenz danach nur noch per Folge-Entscheidung erreichbar.
