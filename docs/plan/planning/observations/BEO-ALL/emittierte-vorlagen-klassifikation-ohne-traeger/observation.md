# Emittierte Vorlagen-Klassifikation ohne Träger

**Sub-Area:** `*` (gesamtes Repo)

Eine Vorlagen-Klassifikation entscheidet mit, ob ein Ort im emittierten Repo überhaupt entsteht:
wird eine Singleton-Vorlage zur wiederkehrenden, verschwindet der Ort, den der mitemittierte Text
weiter als vorhanden beschreibt — und für die emittierte Hälfte weist keine Quelle einen Träger
aus.
