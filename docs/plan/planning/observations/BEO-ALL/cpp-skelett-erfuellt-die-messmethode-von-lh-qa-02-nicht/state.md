Kennung: [`slice-lh-qa-02-messmethode-bekommt-ihren-change-request`](../../../open/slice-lh-qa-02-messmethode-bekommt-ihren-change-request.md) —
bereitet den Change Request an [`LH-QA-02`](../../../../../../spec/lastenheft.md#lh-qa-02--reproduzierbarkeit) vor: die
Messmethode so gefasst, dass die Skelette sie erfüllen. Die Entscheidung zum Change Request trifft der Auftraggeber.

Drei Belege (`evidence/slice-java-skelett.md`, `evidence/slice-python-skelett.md`,
`evidence/slice-csharp-skelett.md`); das C++-Vorkommen steht weiter unter *Benannt, nicht gezählt*. Der Ausgang
wechselt auf *verkörpert*, sobald der Change Request als Commit in `spec/lastenheft.md` steht, und auf
**`gestrichen`** mit Begründung, wenn die Aussage nicht mehr zutrifft: die Messmethode ist per Change Request so
gefasst, dass das Skelett sie erfüllt, oder das Skelett pinnt per Digest.
