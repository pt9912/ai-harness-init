# Mess-Rezept setzt unbenannte Host-Konfiguration voraus

**Sub-Area:** `*` (gesamtes Repo)

Ein Rezept, das eine Messung nachfahrbar machen soll, hängt an einer Einstellung des Hosts, die es
nicht nennt — etwa einer globalen git-Identität. Auf dem Host des Schreibers läuft es, auf einem
anderen bricht es an einer Stelle ab, die mit der Messung nichts zu tun hat. Die Fehlerrichtung ist
*das Rezept ist vollständig*.
