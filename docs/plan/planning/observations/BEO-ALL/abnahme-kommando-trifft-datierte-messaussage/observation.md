# Abnahme-Kommando trifft eine datierte Messaussage

**Sub-Area:** `*` (gesamtes Repo)

Ein Closure-Trigger prüft per `grep` auf einen alten Pin-Wert, dass kein Träger mehr darauf steht,
und trifft eine wahre, datierte Messaussage, die den alten Stand nennen muss. Das Kommando trennt
Pin und Messung nicht; wer es wörtlich erfüllt, schreibt eine Messung um, die niemand neu gemacht hat.
