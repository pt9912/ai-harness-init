# Umschrift eines Zitats ändert die Aussage

**Sub-Area:** `*` (gesamtes Repo)

Ein Artefakt ersetzt ein Zitat aus einer Quelle durch eine eigene Formulierung, etwa weil es die
Quelle nicht mehr nennen darf. Die Umschrift sagt etwas anderes als das Zitat und lässt einen Weg
zu, den dasselbe Artefakt an anderer Stelle ausschließt.

Ein Wächter besteht nicht: Kein Modul aus `modules:` der [`.d-check.yml`](../../../../../../.d-check.yml)
liest den Inhalt einer Aussage. Träger ist das Review.
