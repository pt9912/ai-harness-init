# Emittierter Stand läuft dem Dogfood voraus

**Sub-Area:** `*` (gesamtes Repo)

Eine Regel wird in der Emissions-Vorlage schärfer gefasst als im eigenen Gate: Ein frisch
gebootstrapptes Ziel fährt eine Form, die dieses Repo selbst nicht fährt. Erprobt ist sie über
beiden Bäumen, was fehlt, ist die **Dauerhaftigkeit im eigenen Gate** — der Vorlauf ist kein
Messfehler, sondern ein Zustand ohne Wächter.

Die Fehlerrichtung ist doppelt und darum benennenswert: Solange der Vorlauf besteht, belegt kein
Sensor dieses Repos die Regel, die es an Adopter ausliefert; und ob der Vorlauf je eingeholt
**werden soll**, ist eine eigene Frage — für eine Position kann die Abweichung die richtige
Dauerform sein, weil ein frisches Ziel einen Bestand nicht hat, den dieses Repo führt.
