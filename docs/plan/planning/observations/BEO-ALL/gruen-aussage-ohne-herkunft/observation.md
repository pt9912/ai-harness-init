# Grün-Aussage ohne Herkunft

**Sub-Area:** `*` (gesamtes Repo)

Eine Grün-Aussage nennt ihre Herkunft nicht: *„`make mutate` grün"* trägt denselben Wortlaut für
einen gefahrenen Fall-Satz und für einen zitierten Beleg, und kein Sensor hält einen späteren Text
gegen die Lauf-Art, aus der er stammt.
