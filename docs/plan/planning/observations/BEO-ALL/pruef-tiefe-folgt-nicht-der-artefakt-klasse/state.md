**Stand:** offen

Ein Wächter besteht nicht: Kein Modul aus `modules:` der
[`.d-check.yml`](../../../../../../.d-check.yml) liest Review-Reports, und `make mutate` kennt keine
Fehlschlag-Form, in der eine Prüftiefe rot wird. Die Urteilsgrundlage, die die Klasse fängt — *wann
ist eine Runde hinreichend* —, gehört nach Baseline-Regelwerk `modul-08-agentenrollen.md` §Welche
Rolle braucht welche Artefaktklasse in die Reviewer-Skill; dort steht sie nicht. Geschrieben wird
sie von der Rolle, die sie ausführt
([ADR-0028](../../../../adr/0028-anweisungssatz-gehoert-der-ausfuehrenden-rolle.md)), nicht vom
Planner.
