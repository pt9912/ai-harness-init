# Ein zweiter gleichartiger Fall zieht Begleitstellen eines Mechanismus nicht automatisch nach

**Sub-Area:** `*` (gesamtes Repo)

Kommt zu einem bestehenden Einzelzweck-Mechanismus ein zweiter, gleichartiger Fall hinzu (ein
zweiter Hook neben einem ersten, ein zweiter Zweck einer bestehenden Aktivierung), bleiben
Begleitstellen — eine Probe, eine Beschreibung, ein erklärender Kommentar —, die den ersten Fall
namentlich oder inhaltlich fixieren, ohne Nachzug stehen, bis ein Review sie einzeln findet.
