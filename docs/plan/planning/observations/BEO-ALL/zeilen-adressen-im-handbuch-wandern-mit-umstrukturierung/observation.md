# Zeilen-Adressen im Handbuch sind kein stabiler Anker über eine Umstrukturierung hinweg

**Sub-Area:** `*` (gesamtes Repo)

Slice-Pläne, die einen Nachzug im Benutzerhandbuch adressieren, zitieren die Ziel-Stelle über eine
Zeilennummer. Die Zeile trägt den Stand nur bis zur nächsten strukturellen Änderung des Dokuments —
eine Umstrukturierung verschiebt die Adresse, ohne dass ein Sensor das anzeigt (Anker-/Link-Prüfung
deckt nur benannte `#`-Überschriften, keine Zeilennummern in Prosa). Kein Fix in diesem Repo: eine
strukturell stabilere Adressform für Zeilen-Zitate in Slice-Plänen existiert nicht.
