# Kommentar nennt den Vorgang seiner Entstehung statt der Stelle

**Sub-Area:** `*` (gesamtes Repo)

Ein Kommentar in Code, Konfiguration oder Skript beschreibt, **wie** seine Aussage zustande kam —
das Protokoll eines einmaligen Laufs, die verworfene Alternative, eine Mess-Beteuerung ohne
Kommando — statt der Stelle, an der er steht. Das verletzt
[`AGENTS.md`](../../../../../../AGENTS.md) §3.7, und dessen eigener Satz *„Ein Wächter existiert
nicht"* gilt hier unverändert.

## Benannt, nicht gezählt

Der Nachbareintrag
[`adaptions-block-spricht-ueber-sich-selbst`](../adaptions-block-spricht-ueber-sich-selbst/observation.md)
deckt den Fall nicht: er handelt vom Adaptions-Block und dessen Buchführung über sich selbst,
nicht von Kommentaren in Code und Konfiguration.
