# Push auf den geschützten Hauptzweig läuft über die Regelumgehung

**Sub-Area:** `*` (gesamtes Repo)

Ein Push von `main` geht durch, obwohl die Ausgabe von GitHub „Bypassed rule violations … Cannot update this
protected ref" nennt. Die Regelumgehung des Besitzers trägt den Push; weder die Release-Prozedur noch ein Plan
nennt sie als Träger, und kein Sensor sieht sie.
