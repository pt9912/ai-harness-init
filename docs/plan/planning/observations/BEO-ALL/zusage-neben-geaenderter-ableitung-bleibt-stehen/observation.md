# Zusage neben geänderter Ableitung bleibt stehen

**Sub-Area:** `*` (gesamtes Repo)

Ein Fix, der Verhalten ändert, korrigiert die Ableitung, lässt aber eine daneben stehende Zusage
(Skript-Ausgabe, Testname, Doku-Absatz) unverändert stehen — kein Gate prüft den Wahrheitsgehalt
einer Aussage, nur die Existenz eines genannten Sensors.
