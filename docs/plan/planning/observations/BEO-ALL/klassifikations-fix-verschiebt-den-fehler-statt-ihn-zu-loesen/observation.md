# Ein Fix an einer N-über-M-Klassifikation korrigiert einen Fall und führt einen anderen neu ein

**Sub-Area:** `*` (gesamtes Repo)

Ein Fix, der eine falsch klassifizierte Zelle einer Mehr-Kommandos-×-Mehr-Eigenschaften-Tabelle
korrigiert, prüft dabei nur die explizit im Finding genannten Sätze gegen die Referenz — nicht den
ganzen betroffenen Bereich. Dadurch entsteht an einer anderen Stelle derselben Klassifikation ein
neuer Fehler derselben Art, den erst ein vollständiger, satzweiser Durchgang über den gesamten
Bereich fängt, nicht ein Review, das nur die genannten Sätze erneut liest.

## Benannt, nicht gezählt
