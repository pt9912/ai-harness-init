# Span-Feld wechselt seine Bedeutung ohne Fassungs-Angabe

**Sub-Area:** `*` (gesamtes Repo)

Ein Feld im lokalen Span-Bestand trägt vor und nach einer Änderung dieselbe Bezeichnung mit
verschiedener Regel. Der Bestand ist gitignored, maschinenlokal und append-only, und kein Feld nennt
die Fassung, unter der eine Zeile entstand. Ein Leser, der über die Zeit vergleicht, sieht einen
Sprung, der keine Verhaltensänderung des Beobachteten ist. Die Fehlerrichtung ist *das Feld hat eine
Bedeutung*.
