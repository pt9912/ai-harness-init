# Adaptions-Marker nennt eine Stelle, die die Emissions-Klasse nicht hält

**Sub-Area:** `*` (gesamtes Repo)

Ein `ANPASSEN`-Marker steht in einer **emittierten** Vorlage und lädt den Adopter ein, die
bezeichnete Stelle zu ändern — an einer Stelle, die die **Emissions-Klasse** dieses Artefakts gar
nicht freigibt: Das Artefakt wird bei jedem Bootstrap kanonisch neu geschrieben, und was der Marker
freigibt, ist nach dem nächsten Lauf fort. Der Marker verspricht eine Adapter-Freiheit, die die
Klasse nicht trägt; er widerlegt sich mit dem Satz, der ihn begleitet, wenn der die Klasse nennt.

Die Fehlerrichtung ist *die Stelle ist adaptierbar*: Der Marker macht eine Freiheit **sichtbar**,
und die Sichtbarkeit wird für ihren Bestand gelesen. Anders als eine gewöhnliche Prosa-Zusage ist
der Marker ein **Vorgabeform-Element** — die Vorlage wird verlangt, nicht nur geduldet —, und darum
trifft die Klasse jeden Adopter, dessen Vorlage ihn führt. `ANPASSEN` steht in allen neun
Command- und Agent-Vorlagen, die das Werkzeug emittiert.

## Benannt, nicht gezählt

Zwei Nachbarklassen teilen den Ort — eine **emittierte Vorlage** — und decken den Fall nicht.
[`zusage-neben-geaenderter-ableitung-bleibt-stehen`](../zusage-neben-geaenderter-ableitung-bleibt-stehen/observation.md)
lässt eine Zusage neben einer geänderten Ableitung stehen und meint eine Aussage, die nach ihrem
Wortlaut noch wahr ist; hier lädt der Marker zu einer **Handlung** ein, die die Klasse des
Artefakts nicht trägt.
[`zusage-nennt-sensor-der-form-nicht-sieht`](../zusage-nennt-sensor-der-form-nicht-sieht/observation.md)
setzt einen genannten **Sensor** voraus, dessen Form der Code nicht hält; hier nennt der Marker
keinen Sensor, sondern einen Adressaten.
