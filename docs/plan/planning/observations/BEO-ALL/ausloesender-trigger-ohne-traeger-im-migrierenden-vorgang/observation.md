# Auslösender Trigger ohne Träger im migrierenden Vorgang

**Sub-Area:** `*` (gesamtes Repo)

Ein Auflösungs-Trigger, der auf eine Form-Migration zeigt, feuert mit ihr — aber die Entscheidung,
ob der Eintrag dadurch gegenstandslos wird, hat im migrierenden Vorgang keinen Träger: der Vorgang
wechselt den Träger, das Urteil verlangt eine inhaltliche Prüfung je Eintrag.
