# Eine terse Feld-Notiz im Adopter-Träger kann hinter ihrer Regel zurückbleiben

**Sub-Area:** `*` (gesamtes Repo)

Eine kurze Ein-Satz-Notiz in `SchemaNotes()`, die eine Regel mit vielen Rand-Fällen (z. B.
`commandProgram()`, SPEC-021) knapp nacherzählt, kann selbst wieder unvollständig oder
irreführend werden, sobald die Regel neue Ränder bekommt — ohne dass ein Wächter das
automatisch fängt, weil die Notiz nie Vollständigkeit zusagt und ein Mutations-Fall nur den
heutigen Wortlaut gegen seinen heutigen Rückfall bindet, nicht die künftige Deckung der Regel.
