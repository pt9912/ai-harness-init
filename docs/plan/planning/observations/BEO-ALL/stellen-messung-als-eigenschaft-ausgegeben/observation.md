# Stellen-Messung als Eigenschaft ausgegeben

**Sub-Area:** `*` (gesamtes Repo)

Eine Messung an einer bestimmten Stelle — einem Geber, einer Teilmenge von Elementen — wird als
Eigenschaft des Ganzen ausgegeben, zu dem die Stelle gehört: einer Lifecycle-Kante, einer Form. Die
Größe, an der das Ergebnis tatsächlich hängt, bleibt ungenannt, und der Satz liest sich als Aussage
über alles, was das Ganze umfasst. Die Fehlerrichtung ist *die Eigenschaft ist gemessen*.

Zwei Nachbarklassen decken den Fall nicht.
[`zusage-nennt-zwei-kanten-der-sensor-deckt-eine`](../zusage-nennt-zwei-kanten-der-sensor-deckt-eine/observation.md)
setzt einen Sensor voraus, der nur einen der zwei Zeitpunkte einer Regel urteilt; hier ist kein
Sensor im Spiel, und beide Kanten können gemessen sein — verfehlt ist die Größe, an der das Ergebnis
hängt.
[`exit-zusage-aus-anderem-aufruf-abgeleitet`](../exit-zusage-aus-anderem-aufruf-abgeleitet/observation.md)
verfehlt den Aufruf; hier ist der Aufruf der genannte, und die Messstelle ist enger als der Satz.
