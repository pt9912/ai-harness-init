# Streich-Muster trifft mehr als seine Klasse

**Sub-Area:** `*` (gesamtes Repo)

Eine Regel, die eine Klasse aus Text entfernt (hier: fremde Werkzeug-Kennungen aus adaptierten
`--print-mk`-Fragmenten), greift über ein Muster, das breiter ist als die Klasse, und entfernt auch
Gleichgeformtes ohne Bezug — `(UTF-8)` fiel als Kennung. Die Fehlerrichtung ist *was das Muster
trifft, gehört zur Klasse*; still bleibt es, weil der Wächter nur prüft, dass nichts mehr steht.
