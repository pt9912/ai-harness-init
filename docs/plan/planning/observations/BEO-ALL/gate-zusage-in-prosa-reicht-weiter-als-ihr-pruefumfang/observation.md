# Gate-Zusage in Prosa reicht weiter als ihr Prüfumfang

**Sub-Area:** `*` (gesamtes Repo)

Ein lebendes Artefakt sagt in **Prosa** zu, ein benanntes Gate melde einen Zustand — und der
Prüfumfang des Moduls, das den genannten Grund-Code trägt, ist enger als der Satz. Unter der engen
Lesart bleibt jedes einzelne Wort wahr; was fehlt, ist die Grenze. Die nächste Runde liest den Satz
als Aussage über den Bereich, über den sie ihn liest, und hält einen Ausschnitt für den Bestand.
Die Fehlerrichtung ist *der Bereich ist bewacht*.

Der Ort macht die Klasse teuer: Sie entsteht in der **Korrektur** — in dem Satz, der gerade eine
andere überholte Aussage ersetzt. Eine Zusage in Prosa durchläuft nicht die Verdrahtung, die ein
Gate bei seiner Einführung durchläuft; das rote Gegenbeispiel, das die Reichweite zeigen würde,
fällt mit ihr weg.

## Benannt, nicht gezählt

Zwei Nachbarklassen sind enger und decken den Fall nicht.
[`zusage-nennt-sensor-der-form-nicht-sieht`](../zusage-nennt-sensor-der-form-nicht-sieht/observation.md)
setzt eine Zusage **im Skript- oder Funktionskopf** voraus, deren Geltungsbereich der Code darunter
nicht hält — hier steht kein Code unter der Zusage.
[`zusage-nennt-zwei-kanten-der-sensor-deckt-eine`](../zusage-nennt-zwei-kanten-der-sensor-deckt-eine/observation.md)
trifft die **Zeit**-Achse: zwei Kanten desselben Vorgangs, der Sensor sitzt auf einer. Hier ist die
Achse der **Ausschnitt** — eine Tabellenspalte, ein Prüfbereich, eine Bedingung außerhalb der
Modul-Reichweite.
