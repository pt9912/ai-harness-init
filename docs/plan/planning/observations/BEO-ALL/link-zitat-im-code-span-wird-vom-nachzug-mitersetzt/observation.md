# Ein Link-Zitat im Code-Span wird vom Nachzug mitersetzt

**Sub-Area:** `*` (gesamtes Repo)

Der Nachzug in `docs/reviews/` liest die Adresse hinter `](` als Link und erkennt weder Span-Grenzen noch
Fences; steht Link-Syntax als **Zitat** in einem Code-Span, schreibt er sie um wie einen echten Link. Das
Zitat ist dann nicht mehr, was der Report zeigte. Im Bestand ist die Form inert; die Grenze ist benannt
und gemessen, aber ihr Träger ist ein Re-Evaluierungs-Trigger der Entscheidung, kein Sensor. Die
Fehlerrichtung ist *ein Zitat bleibt, wie es zitiert wurde*.

## Benannt, nicht gezählt

[`verweis-nachzug-ersetzt-eine-historisch-richtige-adresse`](../verweis-nachzug-ersetzt-eine-historisch-richtige-adresse/observation.md)
trifft den Nachzug, der eine historisch richtige Adresse ersetzt und damit die Aussage ändert; hier ist
die Link-Syntax selbst das Zitat, und die Grenze der Form-Regel bleibt als benannte Lücke stehen.
