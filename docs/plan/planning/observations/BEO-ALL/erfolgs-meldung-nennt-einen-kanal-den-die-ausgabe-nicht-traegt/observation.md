# Erfolgs-Meldung nennt einen Kanal, den die Ausgabe nicht trägt

**Sub-Area:** `*` (gesamtes Repo)

Eine Stufe meldet im Erfolg, über welchen von mehreren Wegen ihr Prüfling lief, prüft aber nur eine
Ausgabe, die auf allen Wegen gleich lautet. Den Weg hält dann allein ein Mutationsfall unter
`make mutate`, nicht `make gates`.
