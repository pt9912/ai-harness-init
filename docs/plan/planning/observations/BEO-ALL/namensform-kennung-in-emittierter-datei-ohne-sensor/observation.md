# Namensform-Kennung in emittierter Datei ohne Sensor

**Sub-Area:** `*` (gesamtes Repo)

Eine Kennung in Namensform (`slice-<name>`, `welle-<name>`) in einer emittierten Datei löst im
Ziel nicht auf; kein Sensor erkennt sie, weil ein einfaches Muster sie nicht von Werkzeugnamen wie
`slice-mv` trennt.
