# Entfernungs-Commit trägt eine Addition

**Sub-Area:** `*` (gesamtes Repo)

Der Commit, der den Rumpf eines Adaptions-Eintrags entfernt, setzt im selben Diff die Zeiger-Zeile.
Die Zwei-Commit-Form, die einen reinen Lösch-Diff prüfbar machen soll, ist damit nicht eingehalten;
kein Gate liest die Zusammensetzung eines Commits.
