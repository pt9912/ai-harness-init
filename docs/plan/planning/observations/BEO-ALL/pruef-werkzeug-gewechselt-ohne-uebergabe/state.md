**Stand:** offen

Unterhalb der Schwelle; `offen` ist hier der Normalzustand und kein Ausgang. Kein Sensor hält den
Werkzeug-Wortlaut einer DoD gegen den gelieferten Test; Träger ist das Übergabe-Artefakt an den
Planner, das [`AGENTS.md`](../../../../../../AGENTS.md) §3.10 für eine Änderung der Abnahme verlangt.
