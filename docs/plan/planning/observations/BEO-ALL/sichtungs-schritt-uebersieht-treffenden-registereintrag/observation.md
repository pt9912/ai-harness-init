# Sichtungs-Schritt übersieht einen treffenden Registereintrag

**Sub-Area:** `*` (gesamtes Repo)

Der Sichtungs-Schritt eines Slice-Plans (§8, *Vorgelagert — offene Beobachtungen sichten*) notiert
„kein weiterer Treffer" für eine Sub-Area, obwohl ein bereits mehrfach belegter, thematisch direkt
einschlägiger Registereintrag existiert. Anders als
[`sichtungs-schritt-zitiert-falschen-zaehler-stand`](../sichtungs-schritt-zitiert-falschen-zaehler-stand/observation.md)
(dort wird ein **zitierter** Zähler-Stand falsch benannt) fehlt hier die Erwähnung eines
**zutreffenden** Eintrags vollständig — die Fehlerrichtung ist *kein Treffer notiert* statt *ein
falscher Stand notiert*.
