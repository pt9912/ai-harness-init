# Byte-Gleichheit als Aussage über die Regel gelesen

**Sub-Area:** `*` (gesamtes Repo)

Eine Byte-Gleichheits-Messung an einem Regelwerks-Abschnitt wird als Aussage über die Regel
gelesen, die er stellt — obwohl der Abschnitt Fragen in andere Dateien delegiert, die ein Delta
haben; die Fehlerrichtung ist *unverändert* statt *andere Pflicht*.
