Kennung: `slice-gate-ausgang-schreibt-die-adresse-aus` — er schreibt das Kriterium, das heute keine
Quelle nennt: wann eine von einem Doku-Gate gerötete Fundstelle ihre Adresse ausschreibt, statt die
Zeile mit einem Marker stumm zu schalten oder die Nennung umzuformulieren.

Die Klasse hat keinen Zielort: Ein Wächter wäre in dieser Richtung keiner — ein Gate misst, ob eine
genannte Adresse auflöst, nicht ob eine fehlt; die umformulierte Zeile ist grün, gerade weil sie
keine Adresse mehr trägt. Träger der Wirkung bleibt bis dahin der Lauf, der den Ausgang wählt.
