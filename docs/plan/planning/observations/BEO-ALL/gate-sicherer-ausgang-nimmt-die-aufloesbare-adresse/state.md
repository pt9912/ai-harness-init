**Stand:** offen

Ein Wächter besteht nicht und wäre in dieser Richtung keiner: Ein Gate misst, ob eine genannte
Adresse auflöst, nicht ob eine fehlt — die umformulierte Zeile ist grün, gerade weil sie keine
Adresse mehr trägt. Der Verlust ist damit an keiner Stelle beobachtbar, an der er entsteht. Träger
ist der Lauf, der den Ausgang wählt.
