# Gepinntes Bild ohne Schwachstellen-Scan

**Sub-Area:** `*` (gesamtes Repo)

Das Repo pinnt Fremd-Bilder per Digest, und kein Sensor prüft ein gepinntes Bild auf bekannte
Schwachstellen. Ein Pin ist damit reproduzierbar, aber nicht bewertet: Ein Sprung auf einen neuen
Tag geschieht, ohne dass eine Verwundbarkeit ihn anstößt oder aufhält.
