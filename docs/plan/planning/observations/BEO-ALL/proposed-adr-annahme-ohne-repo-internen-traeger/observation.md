# Proposed-ADR-Annahme ohne repo-internen Träger

**Sub-Area:** `*` (gesamtes Repo)

Eine Entscheidung steht auf `Proposed`, während ein anderer Vorgang ihre **Annahme** als
Start-Bedingung führt — der Vorgang ist damit blockiert, und die Annahme hat keinen
repo-internen Träger, weil keine Quelle dieses Repos den annehmenden Akteur benennt.
