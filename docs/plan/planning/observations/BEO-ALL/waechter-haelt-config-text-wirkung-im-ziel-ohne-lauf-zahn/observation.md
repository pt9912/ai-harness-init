# Wächter hält den Text einer emittierten Config, die Wirkung im Ziel hat keinen Lauf-Zahn

**Sub-Area:** `*` (gesamtes Repo)

Eine Bindung der emittierten Skelett-Config hat einen Text-Wächter, aber keinen Lauf im gebootstrappten
Ziel, der sie rot färbt; die Abdeckungs-Kurzbeschreibung nennt die Lücke am selben Ort. Die Zusage der
Bindung reicht damit nur bis zum Text der Config
([`AGENTS.md`](../../../../../../AGENTS.md) §3.6).
