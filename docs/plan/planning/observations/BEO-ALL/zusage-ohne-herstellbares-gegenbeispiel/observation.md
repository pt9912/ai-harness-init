# Zusage ohne herstellbares Gegenbeispiel

**Sub-Area:** `*` (gesamtes Repo)

Eine Zusage über eine strukturelle Eigenschaft ist hergeleitet statt rot gesehen, weil ihr
Gegenstand außerhalb jeder Sensor-Fläche dieses Repos liegt — nicht ein Sensor ist zu eng, es gibt
gar keinen. [`AGENTS.md`](../../../../../../AGENTS.md) §3.6 verlangt das Gegenbeispiel; wo es nicht
herstellbar ist, bleibt als Ausweg nur, die Zusage auf die Eigenschaft einzuschränken, die der Bau
selbst hält.
