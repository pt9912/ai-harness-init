# Ausnahmeliste nur auf Form geprüft

**Sub-Area:** `*` (gesamtes Repo)

Eine deklarierte Ausnahmeliste wird mechanisch nur auf Existenz und Form geprüft, nie auf
inhaltliche Berechtigung — ob ein Eintrag darin richtig ist, bleibt dauerhaft ein Urteil, und ein
zweiter, unbegründeter Eintrag bliebe für den Wächter unsichtbar.
