# Sensor-Schranke wird durch Tabellenwachstum unscharf

**Sub-Area:** `*` (gesamtes Repo)

Eine Schranke der Form „mindestens N" wird für den Bestand gesetzt. Wächst die gezählte Menge (mehr Tabellen, mehr Zeilen), bleibt die Schranke grün, obwohl Elemente fehlen: der Sensor misst nicht mehr, was die Zusage sagt.
