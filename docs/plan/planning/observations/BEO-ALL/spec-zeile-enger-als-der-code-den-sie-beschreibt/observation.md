# Spec-Zeile enger als der Code, den sie beschreibt

**Sub-Area:** `*` (gesamtes Repo)

Eine Zeile im Technik-Stratum zählt Fälle und Zeichen auf, die der Code führt, und schweigt zu einem
Fall, den Code, Plan-Tabelle und Test gleichermaßen führen; ein Leser der Zeile folgert das
Gegenteil oder nichts. Die Korrektur ist Spec-Text, und für dieses Stratum benennt keine Quelle eine
schreibende Rolle (`slice-151`). Die Fehlerrichtung ist *die Spec beschreibt den Code*.

## Benannt, nicht gezählt

[`vertragliche-aufzaehlung-trifft-den-bestand-nicht`](../vertragliche-aufzaehlung-trifft-den-bestand-nicht/observation.md)
ist dieselbe Richtung in Rang 1, wo ein Change Request die Differenz einholt; hier ist es Rang 2, der
ohne Vertragsänderung fortschreibbar ist.
