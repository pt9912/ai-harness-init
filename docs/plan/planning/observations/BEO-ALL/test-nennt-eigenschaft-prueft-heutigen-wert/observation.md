# Ein Test nennt eine Eigenschaft und prüft den heutigen Wert

**Sub-Area:** `*` (gesamtes Repo)

Ein Test begründet seine Zusicherung mit einer Eigenschaft (*ab dieser Fassung wird `direction:`
dekodiert*) und prüft stattdessen Gleichheit mit dem heute gepinnten Wert. Ein legitimer Pin-Zug auf
eine andere Fassung mit derselben Eigenschaft färbt ihn rot, ein Zug unter die Mindestfassung nur
zufällig aus dem richtigen Grund.
