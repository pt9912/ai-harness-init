# Migrations-Report `v6.7.2` → `v6.8.0`

## Zweck

Der Vorlagen-Report zum Baum-Tausch `v6.7.2` → `v6.8.0`, nach der Report-Form aus
[`harness/migration.md`](../../harness/migration.md) §5. Er ist trivial kurz, und das ist sein
Befund: `git diff v6.7.2..v6.8.0 -- lab/templates` liefert **null** Zeilen
([`ADR-0047`](../plan/adr/0047-ziel-fassung-regiert-den-sprung-v680.md) §Kein Vorlagen-Delta) —
alle 25 Vorlagen sind über die zwei Tags byte-gleich. Für Buchstabe a folgt daraus durchgehend
*schon erfüllt* oder *keine Instanz*, nie *übernommen* oder *bewusst abweichend*; für Buchstabe b
entsteht keine neue Instanz-Pflicht, weil sich die Form nicht geändert hat. Ein anderer Ausgang
wäre hier ein Befund und kein Normalfall (Slice `slice-sprung-auf-v680-wird-vollzogen` §2
Liefer-Punkt 3).
