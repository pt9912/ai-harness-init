```
spec/spezifikation.md:72
**Was die vierte Spalte sagt und was nicht.** Sie nennt den Wächter, der die Zusicherung
der Zeile hält; *Fall N* meint `test/mutations/N-*.sh`. Ein Strich heißt: für diese Zeile
ist kein Wächter namentlich gebunden. Zusicherungen, die keine Zeile dieser Tabelle sind,
stehen im Punkt **Bewacht** am Ende des Abschnitts.
```

Der Absatz sagt, was ein Strich bedeutet — nicht, dass die **Nennung selbst** von keinem
Gate geprüft wird. Und ein Weg zur Grenze existiert nicht:

```
$ grep -n 'MR-0\|conventions\.md' spec/spezifikation.md   -> 0 Treffer
```

Ein solcher Link wäre erlaubt: die `matrix`-Regeln verbieten `spec-straten → adr` und
`spec-straten → slice`, `harness/conventions.md` ist keine der beiden Klassen. Nichts hat
ihn verhindert. Damit steht die Zusage an Rang 2 und ihre Grenze in einem Dokument, von dem
`MR-021` in seiner eigenen Begründung sagt, es stehe *„in keiner der beiden
Precedence-Listen des Repos"*. Gegen §3.6 (*„die Zusage auf das einschränken, was der Code
hält"* · *„benennen, was wirklich deckt — oder dass nichts deckt"*) ist das eine Lücke: der
Leser des bindenden Dokuments erfährt sie nicht.

Der Plan hat die Platzierung ausdrücklich so entschieden (§3: *„Diese Grenze gehört an die
Stelle, an der die Spalte **begründet** wird"*). Das ist eine vertretbare Lesart — §3.6
bindet die Grenze aber an die **Zusage**, nicht an ihre Begründung. **Zwei Sätze im
Absatz `:72` schließen es**, ohne die Zählung in `MR-021` anzutasten.

### 3.2 Die Vollständigkeit der Aufhebung — Grenze vorhanden, ein Hop entfernt

`MR-021` sagt *„Kein Satz seines Rumpfs bindet noch von dort"* und verlinkt im selben Satz
[`ADR-0014`](../plan/adr/0014-aufgehobener-eintrag-kopf-statt-rumpf.md), deren Konsequenzen
lauten: *„die tragende Bedingung 2 (b) hat keinen Wächter. Ob jede bindende Aussage andernorts
steht, entscheidet ein Mensch beim Aufheben; ein Doc-Gate kann diese Eigenschaft nicht
messen (§3.6 — hier benannt, nicht geschlossen)."* Plan §6 sagt es direkt und nennt das
Gegenbeispiel („ein Posten, der still verschwindet — lässt `make gates` grün"). Die Grenze
ist so breit wie das Ungewachte und über einen auflösenden Link von der Zusage aus
erreichbar. **Kein Befund.**
